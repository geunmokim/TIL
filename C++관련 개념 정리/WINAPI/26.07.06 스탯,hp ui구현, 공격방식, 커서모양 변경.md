# 스톤샤드 턴제 RPG 모작 — 기술 구현 노트 (4)

## 1. 마우스 피킹 공격

기존에는 플레이어가 몬스터 인접 칸으로 이동하려 할 때 공격하는 방식이었는데, 마우스 클릭으로 몬스터를 직접 피킹해서 공격하는 방식으로 변경했다.

화면 픽셀 좌표를 격자 칸 번호로 변환할 때 스크롤 역산과 타일 크기 보정이 필요했다. 스프라이트가 칸 중앙에 그려지기 때문에 `TILECX/2`, `TILECY/2`를 더해 기준점을 맞췄다.

```cpp
int iCol = (pt.x - iScrollX + TILECX / 2) / TILECX;
int iRow = (pt.y - iScrollY + TILECY / 2) / TILECY;
```

인벤토리와 같은 `VK_LBUTTON`을 쓰기 때문에 인벤토리가 닫혀있을 때만 공격이 작동하도록 `Is_Open()` 체크를 추가했다. `Key_Down(VK_LBUTTON)`이 10ms 프레임 간격으로 인해 클릭을 놓치는 문제가 있어서 `Key_Pressing(VK_LBUTTON) && m_pDragItem == nullptr` 조건으로 처리한 인벤토리 드래그와 충돌하지 않도록 구분했다.

## 2. 경험치 및 레벨업 시스템

몬스터 처치 시 경험치를 획득하고 일정량이 쌓이면 레벨업하는 시스템을 구현했다.

경험치 지급 흐름은 `NewMonster::Take_Damage()`를 오버라이드해서 몬스터가 죽을 때 플레이어에게 직접 `Add_Exp()`를 호출하는 방식이다. `ObjMgr`를 경유하면 `ObjMgr`가 `NewPlayer.h`를 알아야 하는 의존성 문제가 생기기 때문에 몬스터에서 직접 처리했다.

```cpp
void CNewMonster::Take_Damage(int _dmg)
{
    Obj::Take_Damage(_dmg);  // 부모 함수 호출 (데미지 폰트 포함)
    if (m_bDead)
    {
        CObj* pPlayer = CObjMgr::Get_Instance()->Get_Player();
        if (pPlayer)
            ((CNewPlayer*)pPlayer)->Add_Exp(Get_Exp());
    }
}
```

레벨업 시 초과 경험치가 날아가지 않도록 `m_iExp -= m_iMaxExp`로 처리하고, 다음 레벨업 필요 경험치는 `m_iMaxExp += 50`으로 점진적으로 증가시켰다.

## 3. 데미지 폰트

피격 시 해당 위치에 데미지 숫자가 일정 프레임 동안 표시되다가 사라지는 기능을 구현했다. `CObj`를 상속받아 `ObjMgr`에 등록하면 자동으로 `Update()`/`Render()`/소멸 처리가 되어 별도 관리가 필요 없다.

`Obj::Take_Damage()`에서 생성하면 플레이어/몬스터 피격 시 공통으로 적용된다. 단 `Take_Damage()`가 헤더 인라인으로 구현되면 `ObjMgr`를 참조할 수 없어서 `Obj.cpp`로 분리했고, `Obj.h`에는 `CDamageFont`와 `CObjMgr`를 전방선언만 했다.

```cpp
void CObj::Take_Damage(int _dmg)
{
    m_iHp -= _dmg;
    if (m_iHp <= 0)
        m_bDead = true;

    CFont* pFont = new CFont(_dmg, m_tGridPos);
    pFont->Initialize();
    CObjMgr::Get_Instance()->Add_Object(OBJID::EFFECT, pFont);
    CObjMgr::Get_Instance()->Add_Object(RENDERID::EFFECT, pFont);
}
```

`NewMonster::Take_Damage()`에서 `Obj::Take_Damage()`를 `Obj::Take_Damage(_dmg)`로 직접 호출해 중복 코드 없이 데미지 폰트와 경험치 지급을 함께 처리했다.

## 4. HP바 UI

스톤샤드 에셋에서 `s_hp_n` 스프라이트(167×8px, 2장)를 추출해 HP바를 구현했다. 배경 이미지 위에 현재 HP 비율만큼 채움 이미지를 잘라서 덮어 그리는 방식이다.

```cpp
int iHpWidth = (int)(167.f * ((float)pNewPlayer->Get_Hp() / pNewPlayer->Get_MaxHp()));
BitBlt(_DC, iX, iY, 167, 8, hBgDC, 0, 0, SRCCOPY);
if (iHpWidth > 0)
    BitBlt(_DC, iX, iY, iHpWidth, 8, hFillDC, 0, 0, SRCCOPY);
```

## 5. 마우스 커서 장비 표시

몬스터 위에 마우스를 올렸을 때 무기 스프라이트로 커서를 대체하는 기능을 구현했다. 매 프레임 마우스 위치를 격자 번호로 변환해 `Get_MonsterAt()`으로 몬스터 존재 여부를 확인하고, 있으면 `Stage::Render()`에서 마우스 위치에 무기 스프라이트를 그린다.

```cpp
// Key_Check()에서 매 프레임 체크
g_bCursorOnMonster = (CObjMgr::Get_Instance()->Get_MonsterAt(iRow, iCol) != nullptr);

// Stage::Render()에서 렌더링
if (g_bCursorOnMonster)
{
    GdiTransparentBlt(_DC, pt.x - 24, pt.y - 20, 48, 40,
        hCursorDC, 0, 0, 48, 40, RGB(255, 255, 255));
}
```
