# 스톤샤드 턴제 RPG 모작 — 기술 구현 노트 (5)

## 1. 장비 착용 시 외형 변경

장비 착용 스프라이트는 플레이어 스프라이트와 크기가 동일(48×40px)해서 오프셋 계산 없이 같은 좌표에 덮어씌우는 방식으로 구현했다.

`NewPlayer::Render()`에서 플레이어 스프라이트를 그린 후, `CInven`에서 장착된 아이템 여부를 확인해 해당 장비 스프라이트를 추가로 렌더링한다. 플레이어 좌우 반전(`m_bFlipX`)도 장비 스프라이트에 동일하게 적용된다. 람다 함수로 반전/일반 렌더링을 묶어 코드 중복을 줄였다.

## 2. 공격 이펙트 시스템

공격 시와 피격 시 각각 다른 스프라이트 애니메이션이 재생되는 이펙트 시스템을 구현했다. `CEffect` 클래스 하나에 `EFFECT_TYPE` enum으로 공격/피격을 구분해 관리한다.

```cpp
enum EFFECT_TYPE { EFFECT_ATTACK, EFFECT_HIT };
```

두 이펙트의 프레임 크기가 달라서(`attack_effect`: 프레임 77×68px, `hit_effect`: 프레임 37×37px) `m_iFrameW`, `m_iFrameH`를 멤버로 들고 `Initialize()`에서 타입에 맞게 설정한다. `Render()`에서 현재 프레임 번호에 프레임 가로 크기를 곱해 소스 X 좌표를 계산하는 방식이다.

```cpp
int iSrcX = m_tFrame.iStartX * m_iFrameW;
```

`Obj::Take_Damage()`에서 `EFFECT_HIT`을, `NewMonster::Take_Damage()`에서 `EFFECT_ATTACK`을 생성해 플레이어/몬스터 피격 시 각각 다른 이펙트가 재생된다. `Update_Frame()`이 마지막 프레임에서 0으로 초기화하는 구조라, 한 번만 재생하고 소멸해야 하는 이펙트는 수동으로 프레임을 증가시키고 마지막 프레임에서 `OBJ_DEAD`를 반환하도록 처리했다.

## 3. 이펙트 재생 후 턴 전환

플레이어가 공격하면 이펙트 재생이 끝나기 전에 몬스터 턴으로 넘어가 동시에 공격하는 것처럼 보이는 문제가 있었다. `End_PlayerTurn()`에서 즉시 턴을 전환하는 대신 플래그(`m_bPlayerTurnEnd`)만 세우고, `TurnMgr::Update()`에서 이펙트 리스트가 비었을 때 전환하도록 수정했다.

```cpp
void CTurnMgr::Update()
{
    if (m_bPlayerTurnEnd && CObjMgr::Get_Instance()->Is_EffectEmpty())
    {
        m_eTurnState = ENEMY_TURN;
        m_bPlayerTurnEnd = false;
    }
    if (ENEMY_TURN == m_eTurnState)
        Process_EnemyTurn();
}
```

플레이어 입력도 `m_bPlayerTurnEnd`가 true인 동안 막아서 이펙트 재생 중 연속 공격을 방지했다.

## 4. 마우스 커서 장비 표시

몬스터 위에 마우스를 올리면 기본 커서가 사라지고 무기 스프라이트가 표시되는 기능을 구현했다. 매 프레임 마우스 위치를 격자 번호로 변환해 `Get_MonsterAt()`으로 몬스터 존재 여부를 확인한다.

`ShowCursor()`가 카운터 방식이라 매 프레임 호출하면 누적 문제가 생기므로, 상태가 바뀔 때만 호출하도록 `bPrevCursor` 플래그로 관리했다.

---

## 5. 화살 비행 연출

기존 히트스캔 방식은 화살이 타겟 칸에 바로 배치되어 날아오는 느낌이 없었다. 데미지는 히트스캔으로 즉시 처리하되, 화살 스프라이트가 몬스터 위치에서 플레이어 방향으로 매 프레임 이동하는 시각적 연출을 추가했다.

`Arrow::Update()`에서 현재 GridPos와 타겟 GridPos를 비교해 row/col을 한 칸씩 이동시키고, 타겟에 도달하면 소멸한다. 이동 속도는 거리 기반으로 `m_iLifeFrame = iDistance * 8`로 설정해 거리가 멀수록 자연스럽게 오래 날아가도록 했다.

---

## 6. 플레이어 공격 범위

마우스 피킹 공격에 거리 제한을 추가했다. `PLAYER_ATTACK_RANGE`를 `Define.h`에 정의하고, 몬스터와의 체비셰프 거리가 범위를 초과하면 공격이 무효화된다.
